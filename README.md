# Kompas Indoor — WordPress theme

## Установка

1. Установить и активировать ACF Pro и Contact Form 7.
2. Активировать тему.
3. В ACF синхронизировать доступные группы полей из `acf-json/`.
4. Открыть `Внешний вид → Наполнение Kompas Indoor` и нажать «Заполнить тексты».
5. Назначить меню в области «Основное меню».
6. После наполнения добавить изображения, логотипы и галереи через соответствующие ACF-поля.

## Наполнение контентом

Скрипт `functions/demo-import.php` работает только с контентом и может запускаться повторно.

Он создаёт или обновляет:

- главную страницу;
- страницу «О компании»;
- общую страницу `/uslugi/`;
- страницу `/kejsy/`;
- услугу `/uslugi/raskleyka-obyavleniy/`;
- услугу `/uslugi/rasprostranenie-po-pochtovym-yashchikam/`;
- услугу `/uslugi/promoaktsii/`.

Тексты записываются в реальные поля из `acf-json`. Изображения, галереи и логотипы скрипт не загружает и не очищает. Если медиа уже выбраны вручную, повторный запуск сохраняет их.

SEO Title и Description сохраняются в служебные meta-поля темы. Если во время запуска активен Rank Math или Yoast SEO, значения также записываются в meta-поля соответствующего плагина.

## Contact Form 7

Формы скриптом наполнения не создаются и не перезаписываются. Шорткоды, уже указанные в ACF, сохраняются при повторном запуске.

Стили ошибок находятся в `assets/css/custom.css`, обработка успешной отправки — в `assets/js/custom.js`.


## Вакансии

Тема включает отдельный тип записей **«Вакансии»** (раздел в левой панели WordPress), архив `/vakansii/` и персональные страницы `/vakansii/<slug>/`.

После первого открытия админки при установленном обновлении создаются две вакансии на основе публичных объявлений «Компас-Индор» (координатор и оператор ПК). Ранее созданные вакансии не перезаписываются. Перед публикацией проверьте актуальность зарплат и графиков, при необходимости измените их в WordPress. Чтобы снять объявление с сайта, переведите его в «Черновик».

Для каждой вакансии через **ACF** доступны:
- заработная плата и формат оплаты;
- город/адрес, график, тип занятости, опыт;
- краткое описание для каталога;
- обязанности, требования и условия (редактор со списками);
- ссылка на исходное объявление (только в админке).

Файлы полей: `acf-json/group-vacancies.json` и `acf-json/group-vacancies-options.json`. При необходимости синхронизируйте группы в **ACF → Группы полей → Синхронизация**. Для добавления вакансии выберите **Вакансии → Добавить вакансию** и нажмите «Опубликовать».

**Отклики.** На странице вакансии есть форма «Имя, телефон, почта, сообщение, резюме (необязательно), согласие на обработку данных». Резюме PDF/DOC/DOCX до 7 МБ передаётся почтой и после отправки удаляется из временной директории; в публичной медиатеке оно не хранится. Проверяются nonce, honeypot, тип и размер файла. Сообщения отправляются через `wp_mail` на адрес из **Настройки сайта → Вакансии — настройки → Почта для откликов**. Если адрес не заполнен, используется email администратора сайта.

После обновления темы откройте админку хотя бы один раз: будут созданы вакансии и обновлены правила постоянных ссылок. Для корректной отправки писем настройте SMTP на сервере. В **Настройки → Конфиденциальность** укажите опубликованную политику обработки персональных данных — ссылка появится рядом с согласием. После деплоя проверьте архив, каждую вакансию и отправку тестового отклика.
