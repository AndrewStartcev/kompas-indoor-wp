# Kompas Indoor — WordPress theme

## Установка

1. Установить и активировать ACF Pro и Contact Form 7.
2. Активировать тему.
3. В ACF синхронизировать доступные группы полей из `acf-json/`.
4. Открыть `Внешний вид → Импорт Kompas Indoor` и один раз нажать «Импортировать контент».
5. Назначить меню в области «Основное меню».

Импорт переносит исходные изображения в медиабиблиотеку и записывает attachment ID в ACF. В шаблонах отсутствуют ссылки на `assets/demo-images`: эта папка используется только как источник одноразового импорта. Включая `logo-mark.svg` — он хранится в ACF-группе глобальной шапки.

## Contact Form 7

Импорт автоматически создаёт форму «Расчёт проекта», записывает её shortcode в глобальный popup, форму главной и форму контактов. Стили ошибок находятся в `assets/css/custom.css`, обработка успешной отправки — в `assets/js/custom.js`.
